# Матвей & Самира — сайт-приглашение

24 октября 2026 · Англиканская церковь Святого Андрея, Москва

## Структура

```
index.html                разметка + библиотека SVG (<defs> в начале body)
css/style.css             шрифт, палитра, кружево, ковёр, анимации, адаптив
js/main.js                курсор, прокрутка, таймер, анкета
assets/fonts/             Monomakh Unicode + лицензия
assets/img/               ваши векторные орнаменты
```

Сайт статический: три файла и шрифт, ничего собирать не нужно.
Заливается на любой хостинг как есть.

⚠️ **При каждом обновлении сайта увеличивайте номер версии** в `index.html`:

```html
<link rel="stylesheet" href="css/style.css?v=2">
<script src="js/main.js?v=2"></script>
```

Иначе у гостей, кто уже заходил, останется старая версия из кэша браузера.

Запуск локально:

```bash
python3 -m http.server 4173
```

## Что осталось заменить

# ⚠️ Чтобы анкета начала приходить — 5 минут работы

Форма на сайте уже собирает данные и показывает гостю «Спасибо».
Но пока их некуда складывать: нужна ваша Google-таблица.
Создать её за вас я не могу — нужен доступ к вашему Google-аккаунту.
Шаги ниже делаются один раз.

**1.** Возьмите таблицу — новую (`sheets.new`) или **уже существующую**, любую.

**2.** Откройте **именно эту таблицу** → **Расширения → Apps Script**.
Скрипт привяжется к тому файлу, из которого открыт, поэтому данные пойдут
туда, куда нужно. Удалите то, что там есть, и вставьте:

```js
/* ─── Настройки ─────────────────────────────────── */
var SHEET_NAME  = 'Гости';  // лист, куда писать. Создастся сам, если такого нет
var SHEET_ID    = '';       // пусто, если скрипт открыт из нужной таблицы
var COUNT_MAYBE = true;     // считать ли «пока не уверен(а)» в итоговой сумме
/* ───────────────────────────────────────────────── */

function doPost(e) {
  var data  = JSON.parse(e.postData.contents);
  var ss    = SHEET_ID ? SpreadsheetApp.openById(SHEET_ID)
                       : SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName(SHEET_NAME) || ss.insertSheet(SHEET_NAME);

  // шапка и живые итоги — только при первом заполнении пустого листа
  if (sheet.getLastRow() === 0) {
    sheet.getRange('A1:G1').setValues([['Дата', 'ФИО', 'Придёт', 'Супруг(а)',
                                        'Дети', 'Детей', 'Всего человек']]);
    sheet.getRange('I1').setValue('Итого гостей');
    sheet.getRange('J1').setFormula('=SUM(G2:G)');
    sheet.getRange('I2').setValue('Из них детей');
    sheet.getRange('J2').setFormula('=SUM(F2:F)');
    sheet.getRange('I3').setValue('Заполнили анкету');
    sheet.getRange('J3').setFormula('=COUNTA(B2:B)');
    sheet.getRange('A1:G1').setFontWeight('bold');
    sheet.getRange('I1:I3').setFontWeight('bold');
    sheet.setFrozenRows(1);
  }

  var kidsCount   = (data.kids || []).length;
  var spouseCount = data.spouse ? 1 : 0;

  // сколько человек придёт по этой анкете
  var total = 0;
  if (data.attend === 'yes' || (data.attend === 'maybe' && COUNT_MAYBE)) {
    total = 1 + spouseCount + kidsCount;
  }

  sheet.getRange(nextRow_(sheet), 1, 1, 7).setValues([[
    new Date(),
    data.fio,
    { yes: 'Да', maybe: 'Не уверен(а)', no: 'Не сможет' }[data.attend] || data.attend,
    data.spouse,
    data.kidsText,
    kidsCount,
    total
  ]]);
  return ContentService.createTextOutput('ok');
}

// Первая свободная строка по колонке «Дата».
// Обычный appendRow здесь не подходит: он смотрит на последнюю заполненную
// ячейку любой колонки, а формулы итогов справа сдвинули бы данные вниз.
function nextRow_(sheet) {
  var col = sheet.getRange(1, 1, sheet.getMaxRows(), 1).getValues();
  for (var i = col.length - 1; i >= 0; i--) {
    if (col[i][0] !== '') return i + 2;
  }
  return 2;
}
```

Что получится в таблице:

| Дата | ФИО | Придёт | Супруг(а) | Дети | Детей | Всего человек |
|---|---|---|---|---|---|---|
| 07.09.2026 | Апров Матвей Сергеевич | Да | Апрова Самира | Амина (5), Тимур (2) | 2 | 4 |
| 07.09.2026 | Иванов Иван | Не сможет | | | 0 | 0 |

Справа, в клетках `I1:J3`, живут три живые формулы — они пересчитываются сами
при каждой новой анкете:

* **Итого гостей** — сумма колонки «Всего человек», то есть сколько человек
  придёт всего, вместе с супругами и детьми;
* **Из них детей** — отдельно, удобно для меню и рассадки;
* **Заполнили анкету** — сколько человек вообще ответило.

Тонкости счёта:

* кто ответил «К сожалению, не смогу» — считается за 0;
* «Пока не уверен(а)» по умолчанию **входит** в сумму. Чтобы не входил,
  поставьте вверху скрипта `var COUNT_MAYBE = false;`;
* супруг считается, только если вписано его ФИО;
* дети считаются по числу заполненных полей.

**3.** Синяя кнопка **Развернуть → Новое развёртывание**.
Тип — **Веб-приложение**. «Запуск от имени» — *я*.
«У кого есть доступ» — **у всех**. Развернуть, разрешить доступ, скопировать URL
(он выглядит как `https://script.google.com/macros/s/AKfy…/exec`).

**4.** Откройте `js/main.js`, самая верхняя строка настроек:

```js
var SHEET_URL = '';
```

Вставьте туда скопированный адрес:

```js
var SHEET_URL = 'https://script.google.com/macros/s/AKfy…/exec';
```

Готово. Заполните анкету на сайте — в таблице появится строка.

## Если таблица уже существует

Ничего дополнительного делать не нужно — тот же скрипт, просто вставленный
в Apps Script **этой** таблицы. Что важно знать:

* **Чужие листы не пострадают.** Скрипт работает только с листом `Гости`
  и создаёт его сам, если такого нет. Остальные листы он не трогает.
* **Хотите писать в конкретный лист** — поменяйте `SHEET_NAME` на его название.
  Если в этом листе уже есть строки, шапка не добавится, а анкеты просто
  начнут дописываться снизу в порядке колонок из `appendRow`. Чтобы не сломать
  существующую разметку, лучше завести отдельный лист.
* **Скрипт не обязательно держать внутри таблицы.** Если удобнее отдельный
  проект Apps Script, впишите в `SHEET_ID` идентификатор таблицы — это кусок
  её адреса между `/d/` и `/edit`:
  `docs.google.com/spreadsheets/d/`**`1AbCdEf…XyZ`**`/edit`
* **Если в таблице уже есть свой Apps Script с `doPost`** — двух функций
  с одним именем быть не может. Перенесите тело моей функции внутрь вашей.
* **Если лист `Гости` уже создан со старой шапкой из 5 колонок** — новые
  колонки «Детей» и «Всего человек» сами не появятся: шапка и формулы
  пишутся только в пустой лист. Проще всего удалить этот лист (или
  переименовать) — скрипт создаст его заново уже с итогами. Если удалять
  жалко, допишите заголовки в F1 и G1 руками, а в `I1:J3` вставьте формулы
  `=SUM(G2:G)`, `=SUM(F2:F)`, `=COUNTA(B2:B)`.
* **После любой правки скрипта нужно перевыкладывать:**
  Развернуть → Управление развёртываниями → карандаш → «Версия: новая» → Развернуть.
  Без этого по старому URL продолжит работать прежний код — это самая частая
  причина «поправил, а ничего не изменилось».

Запрос уходит в режиме `no-cors`, поэтому браузер не показывает ответ сервера —
это нормально, проверяйте по строкам в таблице.
Пока `SHEET_URL` пустой, анкета пишется в консоль браузера (F12 → Console),
так что форму можно спокойно тестировать до подключения таблицы.

## Анкета

Поля: **ФИО**, «Придёте ли вы?», галочка «Буду с супругом / супругой»
(раскрывает поле ФИО) и галочка «Буду с детьми» (раскрывает поля с именем
и возрастом плюс кнопку «Добавить ещё ребёнка»). Один человек регистрирует
всю семью сразу.

Отправить незаполненную анкету нельзя: без ФИО и без ответа «Придёте ли вы?»
форма подсвечивает поля, вздрагивает и прокручивает к первой ошибке.
Если отмечена галочка супруга или детей — соответствующие поля тоже обязательны.

После успешной отправки заголовок меняется на «Спасибо!», форма плавно
схлопывается, а между заголовком и текстом раздвигается прорисовывающаяся галочка.

## Карта

Мини-карта — виджет Яндекса, центр по координатам церкви (`37.605265, 55.757982`).

* Сама карта — **картинка**: она не перетаскивается и не ловит прокрутку.
* Кнопок Яндекса не видно: рамка обрезает поля айфрейма вместе с зумом,
  «Пробками» и нижней панелью. Обрезка задана в `.place__map-embed` — айфрейм
  больше рамки на 86 px по бокам и 84 px сверху и снизу. Если Яндекс переставит
  свои кнопки, эти числа можно подкрутить.
* Поверх, ровно по центру (то есть на церкви), стоит наша метка — ковровый медальон.
* **Вся карточка кликабельна**, при наведении снизу выезжает бордовая плашка
  «Открыть в Яндекс.Картах». На телефоне плашка видна всегда.
* Цветокоррекция в два шага, оба в `style.css` рядом:
  1. `filter` на айфрейме снимает половину насыщенности и осветляет
     подложку карты почти до белого;
  2. слой `.place__map-tint` умножается на `--cream` — белое становится
     ровно цветом фона сайта, остальное темнеет пропорционально,
     поэтому карта не мутнеет и садится в страницу.

  Умножение под `@supports`: если браузер не умеет `mix-blend-mode`,
  слой просто прозрачный и карта остаётся под одним фильтром.
  При наведении карта чуть оживает по цвету.

Пока карта грузится (или если её заблокировал адблок) видна запасная карточка
с адресом; после загрузки она плавно уходит.

Под картой подпись «© Яндекс.Карты»: интерфейс сервиса мы спрятали, поэтому
ссылку на источник карты правильно оставить хотя бы текстом.

Другую точку задавать в `index.html`, в `src` айфрейма:
`https://yandex.ru/map-widget/v1/?ll=ДОЛГОТА%2CШИРОТА&z=17&l=map`

## Шрифты

Пара нейтральная, чтобы типографика не тянула акцент ни в одну культуру —
культурный характер держат орнаменты, а не буквы.

* заголовки, имена, время, цифры — **Cormorant Garamond**, классическая антиква;
* основной текст, меню, подписи, поля, кнопки — **Manrope**, спокойный гротеск.

Оба подключены с Google Fonts в `<head>` файла `index.html`.

Задаются тремя переменными в `:root` файла `css/style.css`:

```css
--font-display: 'Cormorant Garamond', serif;   /* заголовки и крупные цифры */
--font-text:    'Manrope', sans-serif;         /* текст */
--font-ui:      var(--font-text);              /* мелкие подписи капслоком */
```

Поменять всю типографику можно этими тремя строками, размеры подтянутся сами.

**Monomakh Unicode** остался в проекте (`assets/fonts/`, лицензия SIL OFL рядом)
и подключён через `@font-face`, но сейчас нигде не используется, поэтому и не
скачивается браузером. Если захочется вернуть славянский акцент — например,
только на имена на обложке — есть готовая переменная:

```css
--font-accent: 'Monomakh', var(--font-display);
```

Подставьте её в `.hero__names` (или в `--font-display`, если нужен акцент везде).

## Кайма обложки и отступы

Высота орнаментальной каймы задана переменной `--lace-h` в `:root`.
От неё считаются верхний отступ меню и нижний отступ обложки — иначе меню
и подсказка «листайте вниз» наезжали на узор. Меняете высоту каймы —
отступы подтягиваются сами.

Размер имён и знака на обложке считается не только от ширины экрана,
но и от высоты (`min(9.2vw, 13.5vh)`): на широком, но низком мониторе
обложка иначе не помещалась в экран и кайма уезжала за край.

## Телефон

* макет проверен на 375 px — горизонтальной прокрутки нет;
* меню сворачивается в бургер (до 820 px), открывается на весь экран,
  фон под ним не прокручивается, закрывается по Esc и при повороте на широкий экран;
* меню начинается с пункта «Начало», он же подсвечен, пока вы наверху страницы;
* карточки «Он» и «Она» встают друг под другом, иллюстрации не искажаются;
* строка ребёнка перестраивается: имя и крестик в первой строке, возраст во второй;
* все нажимаемые элементы не меньше 44 px;
* поля ввода 17 px — Safari не зумит страницу при фокусе;
* курсор-кольцо, магнитные кнопки и наклон карточек включаются только при наличии мыши;
* учтены вырезы экрана (`env(safe-area-inset-*)`), фоновые орнаменты на телефоне
  частично скрыты, чтобы не грузить отрисовку.

прокрутка остаётся плавной. Размер тайла — `background-size`, насыщенность — `opacity`.

## Палитра

Меняется в `:root` в начале `css/style.css`:
`--burgundy` бургунди, `--olive` оливковый, `--cream` молочный.

Цвета сняты с ваших векторов, чтобы орнаменты и текст были одного цвета,
а не почти одного: бургунди `#7D1221`, оливковый `#675F3C`, фон `#FAF6ED`.
Прежние (`#6B1A2B`, `#6E7448`, `#FBF8F2`) отличались на глаз и рядом с
присланными файлами читались как брак печати.

## Анимации

Контуры в карточках «Он» и «Она» прорисовываются при появлении. Длину штриха
каждой линии проставляет скрипт (блок 3b в `main.js`) по её собственной
`getTotalLength()`. Общее значение здесь не годится: у рамок ковра периметр
до 824 единиц, и при коротком штрихе остаток пути уходил в разрыв — линии
не замыкались. Запасное значение 600 остаётся только для `<use>`,
где длину измерить нельзя.


Курсор с догоняющим кольцом, магнитные кнопки, наклон карточек, параллакс фона,
побуквенный выход имён, отрисовка контуров SVG, заливка строк расписания
при наведении, плавающие подписи полей, раскрытие блоков супруга и детей.

Появление блоков при прокрутке: блок ждёт, пока не зайдёт на экран примерно
на четверть, и только тогда всплывает снизу на 56 px из полной прозрачности
за 1,15 секунды — так переход видно, а не «блок уже проявился где-то за краем».
Соседние блоки идут каскадом по 90–100 мс.

Порог — константа `TRIGGER` в блоке 4 в `main.js` (0.78 = верх блока поднялся
выше 78% высоты экрана). Меньше число — блок проявляется глубже на экране.
Длительность и расстояние — в `[data-reveal]` в `style.css`.

Считается это прямым замером положения блоков, а не `IntersectionObserver`:
наблюдатель молчит в неактивной вкладке, и блоки могли остаться прозрачными.

**Если анимаций не видно вообще** — проверьте в системе macOS
«Универсальный доступ → Дисплей → Уменьшение движения». При включённой настройке
браузер сам гасит анимации; сайт это уважает, но плавное проявление
(без сдвига) в этом режиме оставлено.

Всё отключается системной настройкой «уменьшить движение» (`prefers-reduced-motion`).
